# Experiments W/O Stress

A proposed lightweight Python library for numerical experiments in theory-oriented machine learning papers.

**Status:** design discussion. The package name, public API, and first example have not been selected.

Start with:

1. [`docs/PROJECT_BRIEF.md`](docs/PROJECT_BRIEF.md) — purpose and acceptance criteria.
2. [`docs/ARCHITECTURE_DRAFT.md`](docs/ARCHITECTURE_DRAFT.md) — initial boundaries and open questions.
3. [`docs/BUILD_WORKFLOW.md`](docs/BUILD_WORKFLOW.md) — discussion and implementation sequence.

The next step is to pick a real experiment and use it to refine the design documents. Once the public contract is agreed, add a concise `AGENTS.md` and implement one end-to-end example.
